# 串口通信协议

## 概述

树莓派（上位机）与 STC89C52RC 单片机（下位机）之间通过 UART 串口通信。

- 波特率：9600 bps
- 数据位：8
- 停止位：1
- 校验位：无
- 串口设备：树莓派 `/dev/ttyAMA0` 或 `/dev/serial0`

## AA 帧协议（推荐）

完整的请求-响应协议，适用于 `firmware/mcu_final/` 固件。

### 状态机

```
        52RC 发送 0xA1
       (物体检测到)
            │
            ▼
    ┌───────────────┐
    │ 等待 AI 识别   │
    │ 摄像头拍照     │
    │ TFLite 推理    │
    └───────┬───────┘
            │
            ▼
    RPi 发送 AA xx 55
    (分类结果帧)
            │
            ▼
    ┌───────────────┐
    │ 52RC 执行分拣  │
    │ 舵机/电机动作  │
    └───────┬───────┘
            │
            ▼
    52RC 发送 0xCC
    (分拣完成确认)
            │
            ▼
    52RC 发送 0xDD
    (流程结束)
            │
            ▼
    回到等待检测状态
```

### 帧格式

#### 物体检测帧（52RC → RPi）

```
字节 0: 0xA1
```

含义：HC-SR04 超声波传感器检测到物体在预设距离内。

#### 分类结果帧（RPi → 52RC）

```
字节 0: 0xAA      帧头
字节 1: 分类编号   01=可回收, 02=有害, 03=厨余, 04=其他
字节 2: 0x55      帧尾
```

#### 分拣确认帧（52RC → RPi）

```
字节 0: 0xCC
```

含义：52RC 已完成舵机/电机的分拣动作。

#### 流程结束帧（52RC → RPi）

```
字节 0: 0xDD
```

含义：整个检测-识别-分拣流程结束，52RC 回到等待状态。

## 单字符协议（简化版）

适用于 `firmware/mcu_servo_char/` 固件。

### 字符定义

| 字符 | 分类 | 舵机动作 |
|------|------|----------|
| `R` | 可回收 | 舵机转到可回收位置 |
| `H` | 有害 | 舵机转到有害位置 |
| `K` | 厨余 | 舵机转到厨余位置 |
| `O` | 其他 | 舵机转到其他位置 |

### 协议流程

```
52RC 持续检测超声波 → 检测到物体 → 发送触发信号（可选）
RPi 拍照识别 → 发送单字符 R/H/K/O
52RC 收到字符 → 控制舵机/电机 → 完成
```
