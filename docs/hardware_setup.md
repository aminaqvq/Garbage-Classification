# 硬件接线指南

## 树莓派 ↔ 52RC UART
RPi GPIO14(TXD) → MCU P3.0(RXD), GPIO15(RXD) ← P3.1(TXD), GND↔GND
⚠ 3.3V vs 5V, 建议电平转换模块

## 单片机外设（最终版）

| 外设 | 52RC 引脚 | 说明 |
|------|-----------|------|
| HC-SR04 TRIG | P1^0 | |
| HC-SR04 ECHO | P1^1 | |
| 舵机 | P1^5 | 独立供电 |
| 电机 EN/IN1/IN2 | P0^0/P0^1/P0^2 | P0需上拉 |
| 满载 L0-L3 | P0^3,P0^5~P0^7 | 低电平触发 |
| LED×5 | P2^0~P2^4 | 低电平点亮 |

⚠ P0口开漏,需外部上拉(4.7k~10kΩ)
⚠ 舵机/电机独立供电
⚠ 所有GND共地
