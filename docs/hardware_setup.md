# 硬件接线指南

## 硬件清单

| 组件 | 型号 | 数量 | 备注 |
|------|------|------|------|
| 上位机 | 树莓派 4B / 3B+ | 1 | 运行 Python AI 识别脚本 |
| 下位机 | STC89C52RC | 1 | 控制舵机和电机 |
| 超声波传感器 | HC-SR04 | 1 | 检测物体靠近 |
| 舵机 | SG90 | 1-2 | 控制分拣挡板 |
| 直流电机 | 小型直流电机 | 1 | 传送带动力 |
| 电机驱动 | L298N / L9110S | 1 | 驱动直流电机 |
| 摄像头 | USB / CSI | 1 | 采集垃圾图像 |
| 杜邦线 | 公母/母母 | 若干 | |
| 面包板 | | 1 | |
| 电源 | 5V/2A | 1-2 | 树莓派和 52RC 分别供电 |

## 树莓派 ↔ 52RC 串口连接

| 树莓派 GPIO | 52RC 引脚 | 说明 |
|-------------|-----------|------|
| GPIO14 (TXD) | P3.0 (RXD) | 树莓派发送 → 52RC 接收 |
| GPIO15 (RXD) | P3.1 (TXD) | 树莓派接收 ← 52RC 发送 |
| GND | GND | 共地 |

**注意**：52RC 是 5V 电平，树莓派 GPIO 是 3.3V。建议使用电平转换模块或至少串联 1kΩ 电阻。

## HC-SR04 超声波传感器 ↔ 52RC

| HC-SR04 | 52RC 引脚 | 说明 |
|---------|-----------|------|
| VCC | 5V | 电源 |
| GND | GND | 共地 |
| Trig | P2.0 | 触发信号 |
| Echo | P2.1 | 回响信号 |

## SG90 舵机 ↔ 52RC

| SG90 | 52RC 引脚 | 说明 |
|------|-----------|------|
| 信号线 (橙) | P1.0 | PWM 控制 |
| 电源 (红) | 5V | 建议独立供电 |
| 地线 (棕) | GND | |

## 直流电机 ↔ L298N ↔ 52RC

| L298N | 52RC 引脚 | 说明 |
|-------|-----------|------|
| IN1 | P1.2 | 方向控制 |
| IN2 | P1.3 | 方向控制 |
| ENA | P1.1 | PWM 调速（可选） |
| VCC | 5V-12V | 电机电源 |
| GND | GND | |

## 摄像头 ↔ 树莓派

- USB 摄像头：直接插入 USB 口
- CSI 摄像头：连接到 CSI 排线接口

## 注意事项

1. **电源**：舵机和电机必须独立供电，不要从 52RC 取电
2. **共地**：所有模块的 GND 必须连接在一起
3. **电平转换**：树莓派 GPIO 是 3.3V，52RC 是 5V，串口通信必须做电平转换
4. **散热**：L298N 长时间工作会发热，必要时加散热片
