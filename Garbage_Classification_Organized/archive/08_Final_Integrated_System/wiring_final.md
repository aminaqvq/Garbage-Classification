# 最终接线说明

## 树莓派 ↔ 52RC UART
| 树莓派 | 52RC | 说明 |
|--------|------|------|
| GPIO14 TXD | P3.0 RXD | 交叉 |
| GPIO15 RXD | P3.1 TXD | 交叉 |
| GND | GND | 共地 |
⚠ 3.3V vs 5V 需电平转换模块

## 单片机外设

| 外设 | 52RC 引脚 | 说明 |
|------|-----------|------|
| HC-SR04 TRIG | P1^0 | 超声波触发 |
| HC-SR04 ECHO | P1^1 | 超声波回响 |
| 舵机信号 | P1^5 | 软件PWM |
| 电机 EN/IN1/IN2 | P0^0/P0^1/P0^2 | P0需上拉 |
| L0满载传感器 | P0^3 | 低电平=满载 |
| L1满载传感器 | P0^5 | 低电平=满载 |
| L2满载传感器 | P0^6 | 低电平=满载 |
| L3满载传感器 | P0^7 | 低电平=满载 |
| LED 可回收 | P2^0 | 低电平亮 |
| LED 厨余 | P2^1 | 低电平亮 |
| LED 有害 | P2^2 | 低电平亮 |
| LED 其他 | P2^3 | 低电平亮 |
| LED 检测 | P2^4 | 低电平亮 |

⚠ P0 口开漏, 需外部上拉(4.7k~10kΩ)
⚠ 舵机/电机独立供电, 所有GND共地
