# 01 — 数据集采集

## 1. 这个文件夹是干什么的

使用 OpenCV 打开摄像头，在预览画面中采集垃圾分类图片。支持四类（可回收/有害/厨余/其他），可以自动定时采集或手动单张拍照。采集的图片按类别保存到 `dataset/<类别>/` 目录。

## 2. 包含的脚本

| 文件名 | 类型 | 作用 | 是否推荐使用 |
|--------|------|------|-------------|
| `collect_dataset.py` | PC Training Python | 摄像头图像采集工具 | ✅ 推荐 |

## 3. 工作流程

1. 运行脚本 → 选择当前要采集的类别
2. 设定目标采集张数（可选）
3. 设定清晰度阈值和拍照间隔
4. 打开摄像头 → 预览画面显示清晰度/亮度/各类别已有数量
5. 按空格开始采集 → 自动按间隔拍照
6. 按 s 手动拍照，p 暂停/继续，q 退出
7. 图片保存到 `dataset/` 目录

## 4. 运行方法

```bash
cd 01_Dataset_Collection/
python collect_dataset.py
```

**配置项（在脚本顶部 CONFIG 区）**：
- `CAMERA_INDEX = 1` — 摄像头编号（笔记本内置=0，外接=1）
- `CAPTURE_INTERVAL = 1.5` — 自动拍照间隔秒数
- `DEFAULT_SHARPNESS_THRESHOLD = 100` — 清晰度阈值

## 5. 输出目录

```
dataset/
  可回收/
  有害/
  厨余/
  其他/
  capture_log.csv
```

## 6. 注意事项

- 图片编号基于已有最大编号递增，不会覆盖已有文件
- 脚本包含中文文件名兼容处理（`imencode + tofile`）
- 这是数据采集阶段，运行在 PC 端
- 不是最终运行版本
