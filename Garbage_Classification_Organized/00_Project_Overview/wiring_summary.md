# 硬件接线汇总

## 一、最终版接线（10_Final_Integrated_System）

### 树莓派 ↔ 52RC 单片机 UART

| 树莓派 GPIO | 52RC 引脚 | 说明 |
|-------------|-----------|------|
| GPIO14 (TXD) | P3.0 (RXD) | 树莓派发送 → 单片机接收 |
| GPIO15 (RXD) | P3.1 (TXD) | 树莓派接收 ← 单片机发送 |
| GND | GND | 共地 |

⚠ **电平转换**：树莓派 GPIO 是 3.3V，52RC 是 5V。建议使用电平转换模块或至少串联 1kΩ 电阻。

### 单片机外设

| 外设 | 52RC 引脚 | 方向 | 说明 |
|------|-----------|------|------|
| HC-SR04 TRIG | P1^0 | 输出 | 超声波触发信号 |
| HC-SR04 ECHO | P1^1 | 输入 | 超声波回响信号 |
| SG90 舵机信号 | P1^5 | 输出 | PWM 控制 |
| L298N EN | P0^0 | 输出 | 电机使能 |
| L298N IN1 | P0^1 | 输出 | 电机方向1 |
| L298N IN2 | P0^2 | 输出 | 电机方向2 |
| LED 可回收 | P2^0 | 输出 | 低电平点亮 |
| LED 厨余 | P2^1 | 输出 | 低电平点亮 |
| LED 有害 | P2^2 | 输出 | 低电平点亮 |
| LED 其他 | P2^3 | 输出 | 低电平点亮 |
| LED 检测状态 | P2^4 | 输出 | 低电平点亮，闪烁=未检测，常亮=检测到 |

### 电源注意事项
- 树莓派：5V/2.5A 独立供电
- 52RC：5V 供电（USB-TTL 或独立电源）
- 舵机：**必须独立供电**（5V，不要从 52RC 取电）
- 电机：通过 L298N 供电（5V-12V）
- 所有模块 GND 必须共地
