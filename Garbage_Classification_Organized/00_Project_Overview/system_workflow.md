# 系统完整工作流程

## 训练流程（PC端）
01 采集 → 02 划分 → 03 训练 → 04 量化导出 → 部署到树莓派

## 最终部署流程（10_Final_Integrated_System）

```
MCU 检查满载 (L0-L3)
  ├─ 满载 → 发送F → 暂停
  └─ 未满载 → HC-SR04 检测垃圾
       ├─ 未检测到 → LED闪烁, 继续等待
       └─ 检测到 → 发送T
            → 树莓派收到T → 拍照AI识别
            → 树莓派发送 R/K/H/O
            → MCU 再次确认未满载
            → 舵机转向 + 电机推出/回位
            → MCU 发送 D
            → 冷却后回到等待状态
```

## 异常流程
- 满载：MCU→F, 树莓派暂停; 解除→MCU→N, 恢复
- 超时/非法：MCU→E, 双方回到等待
