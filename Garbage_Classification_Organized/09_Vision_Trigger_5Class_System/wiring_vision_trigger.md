# 最终接线说明 — 五分类视觉触发版

## 1. 树莓派 ↔ STC89C52RC UART

| 树莓派 GPIO | 连接 | STC89C52RC | 说明 |
|-------------|------|------------|------|
| TXD (GPIO14, pin 8) | → 电平转换 → | RXD (P3.0) | 3.3V → 5V |
| RXD (GPIO15, pin 10) | ← 电平转换 ← | TXD (P3.1) | 5V → 3.3V |
| GND | — | GND | 必须共地 |

**电平转换方案**:
- 推荐用 4 通道双向电平转换模块（如 BSS138 方案）
- 或用电阻分压（树莓派 RX: 5V → 2kΩ+3.3kΩ 分压到 3.3V）
- ⚠ 不可将 5V TXD 直连树莓派 3.3V RXD，会烧 GPIO！

## 2. 舵机接线

| 舵机引脚 | 连接 |
|---------|------|
| 信号线（橙/白） | P1^5 |
| 电源线（红） | 外部 5V-6V 电源正极（**不可从 52RC VCC 取电！**） |
| 地线（棕/黑） | 外部电源负极 + 52RC GND（共地） |

## 3. 电机驱动接线 (L298N / L9110S)

| 驱动模块 | STC89C52RC | 说明 |
|---------|------------|------|
| ENA (使能) | P0^0 | 需外部上拉 4.7kΩ（P0 口开漏） |
| IN1 | P0^1 | 需外部上拉 |
| IN2 | P0^2 | 需外部上拉 |
| 电机电源 | 外部 5-12V 电源 | 独立供电 |
| GND | 52RC GND | 共地 |

## 4. 满载传感器 (L0-L3)

| 传感器 | STC89C52RC | 说明 |
|--------|------------|------|
| L0 | P0^3 | 低电平 = 满载（需外部上拉 4.7k~10kΩ） |
| L1 | P0^5 | 同上 |
| L2 | P0^6 | 同上 |
| L3 | P0^7 | 同上 |
| VCC | 5V (或 3.3V，视传感器型号) | |
| GND | 52RC GND | 共地 |

传感器型号可为：红外对射、微动开关、光电开关。低电平有效。

## 5. 重要提醒

1. **P0 口外部上拉**：STC89C52RC 的 P0 口是开漏结构，作为输入时必须外部上拉 4.7k~10kΩ 到 VCC。
2. **电机/舵机独立供电**：不要从 52RC 或树莓派取电，否则可能复位或烧毁。
3. **共地**：树莓派、52RC、舵机电源、电机电源的 GND 必须连接在一起。
4. **3.3V/5V 电平转换**：树莓派 UART 是 3.3V，52RC 是 5V，必须加电平转换。
5. **串口终端**：树莓派运行脚本前必须关闭 `serial-getty@ttyAMA0.service`（或 ttyS0）。

## 6. 已移除的硬件

以下硬件**不在**新版系统中：
- HC-SR04 超声波传感器（TRIG/ECHO 引脚）
- 超声波相关接线和分压电路
