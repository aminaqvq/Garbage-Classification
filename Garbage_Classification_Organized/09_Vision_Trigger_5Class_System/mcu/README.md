# MCU — STC89C52RC 最终固件

## 文件

`mcu_vision_trigger_full_load_rkho.c` — 五分类视觉触发版单片机固件。

## 功能

- 接收 R/K/H/O 分类命令
- 控制舵机角度 + 电机推出/回位
- 满载传感器检测 (L0-L3)
- 满载变化时发送 F/N
- 分拣完成后发送 D
- 非法字符发送 E
- 满载时禁止执行分类动作

## 协议

RPi→MCU: R(可回收) K(厨余) H(有害) O(其他)
MCU→RPi: D(完成) F(满载) N(恢复) E(错误)

## 烧录

1. 使用 Keil C51 编译 → 生成 HEX 文件
2. 使用 STC-ISP 软件下载到 STC89C52RC
3. 晶振: 11.0592 MHz
4. 波特率: 9600 bps

## 重要提醒

- P0 口开漏，接传感器和电机驱动时必须外部上拉 4.7k~10kΩ
- 舵机和电机必须独立供电
- 不含 HC-SR04 超声波，不需要 TRIG/ECHO 引脚
