# 06 — 串口握手协议测试

## 1. 这个文件夹是干什么的

在正式运行最终系统之前，用这个工具**手动验证树莓派和 52RC 单片机之间的串口通信是否正常**。支持完整的 AA xx 55 帧协议模拟（0xA1 触发 / AA xx 55 分类 / 0xCC ACK / 0xDD DONE）。

## 2. 包含的脚本

| 文件名 | 类型 | 作用 | 是否推荐使用 |
|--------|------|------|-------------|
| `serial_handshake_test.py` | Test Script | 串口 AA 帧协议手动测试 | ✅ 调试用 |
| `mcu_led_test_firmware.c` | MCU C | 超声波+LED+UART 测试固件 | 测试用 |

## 3. 工作流程

```
1. 单片机发送 0xA1（超声波检测到物体）
2. 树莓派收到后，终端提示用户输入分类编号
3. 用户输入 1/2/3/4
4. 树莓派发送 AA xx 55
5. 单片机回复 0xCC (ACK)
6. 单片机回复 0xDD (DONE)
7. 树莓派记录本轮完成
```

## 4. 串口协议

| 方向 | 数据 | 含义 |
|------|------|------|
| MCU → RPi | 0xA1 | 检测到物体 |
| RPi → MCU | AA 01 55 | 可回收 |
| RPi → MCU | AA 02 55 | 厨余 |
| RPi → MCU | AA 03 55 | 有害 |
| RPi → MCU | AA 04 55 | 其他 |
| MCU → RPi | 0xCC | ACK 确认 |
| MCU → RPi | 0xDD | 动作完成 |

## 5. 单片机外设接线

| 外设 | 52RC 引脚 |
|------|-----------|
| HC-SR04 TRIG | P1^0 |
| HC-SR04 ECHO | P1^1 |
| LED 可回收 | P2^0 |
| LED 厨余 | P2^1 |
| LED 有害 | P2^2 |
| LED 其他 | P2^3 |
| LED 检测状态 | P2^4 |

## 6. 运行方法

```bash
# 树莓派端
cd 06_Serial_Handshake_Test/
python3 serial_handshake_test.py

# 单片机：烧录 mcu_led_test_firmware.c
```

⚠ **此固件只有 LED 指示和超声波检测，没有舵机/电机**。
这是协议验证版本的固件，用于确认串口通信正常。

## 7. 注意事项

- 这是一个**调试工具**，不是最终运行版本
- 需要人工在终端输入分类编号
- 固件无舵机/电机控制，仅 LED 指示
