# 最终系统完整接线图

## 1. 树莓派 ↔ 52RC 单片机（UART 串口）

```
树莓派                    52RC 单片机
┌──────────┐             ┌──────────────┐
│ GPIO14   │─── TXD ────▶│ P3.0 (RXD)   │
│ (TXD)    │             │              │
│          │             │              │
│ GPIO15   │◀── RXD ──── │ P3.1 (TXD)   │
│ (RXD)    │             │              │
│          │             │              │
│ GND      │──── GND ────│ GND          │
└──────────┘             └──────────────┘

波特率：9600 bps, 8N1
⚠ 树莓派 GPIO 是 3.3V，52RC 是 5V
  必须使用电平转换模块或至少串联 1kΩ 电阻
```

## 2. HC-SR04 超声波传感器 ↔ 52RC

```
HC-SR04                   52RC
┌──────────┐             ┌──────────────┐
│ VCC  ─────── 5V ───────│ VCC          │
│ GND  ─────── GND ──────│ GND          │
│ TRIG ──────────────────│ P1^0         │
│ ECHO ──────────────────│ P1^1         │
└──────────┘             └──────────────┘
```

**检测距离**：约 5-15cm（由 C 代码中 `DETECT_DISTANCE_CM` 宏定义）

## 3. SG90 舵机 ↔ 52RC

```
SG90                      52RC
┌──────────┐             ┌──────────────┐
│ 橙(信号)  ──────────────│ P1^5         │
│ 红(电源)  ─── 5V ──────│ 独立电源      │  ← 不要从 52RC 取电！
│ 棕(地)   ─── GND ──────│ GND          │
└──────────┘             └──────────────┘
```

⚠ **舵机必须独立供电**，不要从 52RC 开发板取 5V。  
从 C 代码中提取的角度映射：
- 可回收 (0x01)：`angle = 6`，舵机角度约 0°
- 厨余 (0x02)：`angle = 14`，舵机角度约 90°
- 有害 (0x03)：`angle = 22`，舵机角度约 135°
- 其他 (0x04)：`angle = 30`，舵机角度约 180°

## 4. 直流电机 + L298N 驱动 ↔ 52RC

```
L298N                     52RC
┌──────────────┐         ┌──────────────┐
│ ENA ───────────────────│ P0^0 (EN)    │  ← 使能
│ IN1 ───────────────────│ P0^1 (IN1)   │  ← 方向1
│ IN2 ───────────────────│ P0^2 (IN2)   │  ← 方向2
│ VCC (逻辑) ── 5V ──────│ VCC          │
│ GND ──────── GND ──────│ GND          │
│ VCC (电机) ── 5V-12V ──│ 独立电源      │  ← 电机电源
├──────────────┤         └──────────────┘
│ OUT1 ──── 电机 +       │
│ OUT2 ──── 电机 -       │
└──────────────┘
```

电机动作（从 C 代码提取）：
- 开门（推出）：EN=1, IN1=1, IN2=0，延时约 1000ms
- 停止：EN=0，延时约 1000ms
- 关门（回位）：EN=1, IN1=0, IN2=1，延时约 1000ms
- 停止：EN=0

## 5. 分类指示灯 ↔ 52RC

```
LED                       52RC              分类
┌──────────┐             ┌──────────────┐
│ LED1 ──── 220Ω ────────│ P2^0         │  可回收
│ LED2 ──── 220Ω ────────│ P2^1         │  厨余
│ LED3 ──── 220Ω ────────│ P2^2         │  有害
│ LED4 ──── 220Ω ────────│ P2^3         │  其他
│ LED5 ──── 220Ω ────────│ P2^4         │  检测状态
└──────────┘             └──────────────┘

LED 均为低电平点亮，需串联 220Ω 限流电阻。
检测状态 LED：未检测到物体时闪烁，检测到时常亮。
```

## 6. 电源总结

| 组件 | 电压 | 供电方式 |
|------|------|----------|
| 树莓派 | 5V/2.5A | 独立电源适配器 |
| 52RC 单片机 | 5V | USB-TTL 或独立电源 |
| SG90 舵机 | 5V | **独立供电** |
| L298N 逻辑 | 5V | 与 52RC 共用 |
| L298N 电机 | 5V-12V | 独立电源（根据电机规格） |
| LED 指示灯 | — | 通过 220Ω 从 52RC 引脚取电 |

⚠ **所有模块的 GND 必须共地**
