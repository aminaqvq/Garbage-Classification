# 最终串口通信协议详解

## 1. 物理层

- 接口：UART 串口
- 波特率：**9600 bps**
- 数据位：8
- 停止位：1
- 校验位：无（8N1）
- 电平：树莓派 3.3V TTL ↔ 52RC 5V TTL（需电平转换）

## 2. 帧格式 — 分类结果帧（RPi → MCU）

```
字节 0：0xAA       帧头
字节 1：分类编号    01=可回收  02=厨余  03=有害  04=其他
字节 2：0x55       帧尾
```

## 3. 单字节信号

### MCU → RPi

| 字节 | 宏定义 | 含义 | 触发条件 |
|------|--------|------|----------|
| `0xA1` | MCU_TRIGGER_READY | 超声波检测到物体 | HC-SR04 测距 < 阈值 |
| `0xCC` | MCU_ACK_RECEIVED | 已正确收到分类帧 | 帧头 0xAA + 帧尾 0x55 均正确 |
| `0xDD` | MCU_DONE | 分拣动作全部完成 | 舵机+电机动作结束 |
| `0xEE` | MCU_ERROR | 超时/异常 | 等待分类帧超时 |

### RPi → MCU

| 字节 | 含义 |
|------|------|
| `AA 01 55` | 分类结果：**可回收** |
| `AA 02 55` | 分类结果：**厨余** |
| `AA 03 55` | 分类结果：**有害** |
| `AA 04 55` | 分类结果：**其他** |

## 4. 分类编号与 index 的对应关系

⚠ **重要**：帧协议中的分类编号与模型输出的 index 不同！

| 模型 index | 类别 | 帧编号（发送给 MCU） |
|-----------|------|---------------------|
| 0 | 其他 | `0x04` |
| 1 | 厨余 | `0x02` |
| 2 | 可回收 | `0x01` |
| 3 | 有害 | `0x03` |

从 Python 代码中提取的映射逻辑：
```python
CLASS_TO_FRAME_ID = {"可回收": 0x01, "厨余": 0x02, "有害": 0x03, "其他": 0x04}
```

## 5. 正常通信流程（时序图）

```
时间 →

MCU:  [超声波检测]──[发送0xA1]────────────────────[接收AA xx 55]──[舵机+电机]──[发送0xCC]──[发送0xDD]
                        │                              ▲              │            │         │
RPi:                    ├──[收到0xA1]──[AI识别]──[发送AA xx 55]──┤              │            │         │
                        │                                          │              │            │         │
                        └── 去抖等待 0.8s ────────────────────────┘              │            │         │
                                                                                  └── 等待ACK ──┘            │
                                                                                                └── 等待DONE ──┘
```

## 6. 超时参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 触发去抖 | 0.8s | 收到 0xA1 后去抖等待 |
| AI 识别超时 | 4.0s | 最大识别时间 |
| ACK 超时 | 2.0s | 等待 0xCC 的最大时间 |
| DONE 超时 | 12.0s | 等待 0xDD 的最大时间（舵机+电机动作耗时） |

## 7. 异常处理

| 场景 | MCU 行为 | RPi 行为 |
|------|----------|----------|
| MCU 发送 0xA1 后等不到分类帧 | 超时后发送 0xEE，回到等待 | — |
| RPi 发送 AA xx 55 后等不到 ACK | — | 超时后记录失败，回到等待 |
| RPi 等不到 DONE | — | 超时后记录超时，回到等待 |
| MCU 收到非法分类帧 | 忽略，继续等待 | — |
| 超声波持续检测到物体 | 不会重复发 0xA1（去抖） | — |
